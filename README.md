# 团队通 TeamChat

面向小团队内部沟通的**端到端加密即时聊天工具**。

- 一套源码，覆盖 **Windows / macOS / Linux / Android / iOS（需自行签名）/ 鸿蒙（社区 Flutter 分支构建）**
- 后端使用你自己的 **Supabase**（免费版即可），**服务端不存明文**：即使数据库被拖库，没有成员口令也无法解密任何消息
- 聊天记录**24 小时自动销毁**，客户端**不落盘**聊天记录（全部只缓存在内存）
- 支持**全员群、私聊、群聊**，发送**文本 / 图片 / 文件**
- 任何人都可以**一键清空**与对方（或群）的全部聊天记录 —— 服务端与所有成员设备同步清除

## 工作原理（30 秒了解）

```
你的设备                           Supabase（你的私有后端）               同事的设备
┌─────────────┐  密文消息/密文文件   ┌──────────────────┐   Realtime 推送   ┌─────────────┐
│ 内存中解密   │ ─────────────────▶ │ 只存密文，不认识密钥 │ ───────────────▶ │ 内存中解密   │
│ 不存聊天记录 │ ◀───────────────── │ 24h 自动销毁       │ ◀─────────────── │ 不存聊天记录 │
└─────────────┘                    └──────────────────┘                   └─────────────┘
```

- 每个成员注册时在本地生成密钥对，私钥用你设置的口令加密后存在服务端（服务端拿不到口令，解不开）
- 每条消息、每个文件都用会话密钥加密；会话密钥通过成员公钥逐一封装分发
- 客户端每次启动都从服务端拉取当前会话**最近的**消息（滚动到顶部再懒加载更早的），本地不留痕

## 快速开始

1. **准备后端（只需做一次，约 5 分钟）**：注册 [Supabase](https://supabase.com) 免费账号并创建一个项目，拿到 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`，执行两个 SQL 文件。
   👉 **手把手教程见 [docs/setup-supabase.md](docs/setup-supabase.md)（有截图级步骤说明）**
2. **下载并打开客户端**（见下），首次运行填入 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`
3. **注册账号**：设置「账号、密码、昵称」→ 昵称会展示给团队其他成员
4. 注册后自动加入**全员群**，即可开始聊天；把 URL 和 KEY 发给同事，他们就能加入同一个团队
5. 完整使用说明（发图、发文件、建群、清空记录等）见 [docs/user-guide.md](docs/user-guide.md)

## 邀请同事加入

**知道 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY` 的人，就是同一个团队的人。** 把这两个值（或直接让他们用同一个安装包并转发配置）发给同事即可。

安全提醒：因为「知道 KEY 即可加入」，请只在你信任的小团队内部分发这两个值。任何人拿到 KEY 都能注册账号进入团队。

## 常见问题

**Q：忘记密码怎么办？**
密码同时用于「登录」和「解密私钥」。忘记密码将无法解密历史消息，只能用新账号重新注册。请妥善保管密码。

**Q：真的不会在本地留下聊天记录吗？**
客户端不会把消息写入磁盘或数据库，只在运行期间缓存在内存；退出程序即消失。为发送/查看附件而生成的临时文件会在完成后立即删除。唯一的本地持久化数据是：Supabase 地址、KEY、以及登录会话令牌（不包含消息内容）。

**Q：消息多久销毁？**
服务端 24 小时自动删除过期消息与对应文件。任何人也可以随时手动「清空聊天记录」，所有成员设备上的记录会同步消失。

**Q：Supabase 免费版够用吗？**
小团队日常沟通足够（免费版：500MB 数据库、1GB 文件存储、5GB 流量/月）。注意免费项目长时间无活动会被暂停，需在控制台手动恢复。

**Q：部署后端复杂吗？**
不需要写代码：注册 Supabase → 创建项目 → 粘贴执行两个 SQL 文件 → 部署一个清扫函数，全程照抄 [docs/setup-supabase.md](docs/setup-supabase.md) 即可。

**Q：可以用同一个客户端连不同团队吗？**
可以。设置页退出登录后可重新配置新的 Supabase 地址；不同地址即不同团队。

## 安全设计

- **端到端加密**：消息与文件使用 XChaCha20-Poly1305；会话密钥用 X25519 封装后分发，服务端只有密文
- **口令保护私钥**：私钥经 Argon2id 从口令派生密钥加密后才上传，Supabase 无法解密（数据库管理员也不能）
- **24 小时销毁**：服务端定时删除过期消息，附件随消息一同删除
- **随时清空**：任何成员可清空会话，服务端硬删除 + Realtime 通知所有在线成员立即清内存

详细威胁模型与已知边界见 [docs/architecture.md](docs/architecture.md) 与 [SECURITY.md](SECURITY.md)。
