Flutter 客户端源码（Windows / macOS / Linux / Android / iOS / 鸿蒙共用）。

- 项目介绍与后端搭建：[../README.md](../README.md)、[../docs/setup-supabase.md](../docs/setup-supabase.md)
- 用户教程：[../docs/user-guide.md](../docs/user-guide.md)
- 各平台构建：[../docs/build-platforms.md](../docs/build-platforms.md)

```bash
flutter pub get
flutter run -d windows   # 或 macos / linux / 连接的手机
flutter test             # 运行加密与分块单元测试
flutter build windows --release
flutter build apk --release
```
