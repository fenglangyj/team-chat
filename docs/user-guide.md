# 用户教程

本文假设你已经完成 [Supabase 后端准备](setup-supabase.md)，拿到了 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`。

## 1. 首次运行：连接你的团队

1. 打开团队通客户端，看到「连接团队服务器」页面
2. 粘贴两个值：
   - **SUPABASE_URL**：`https://xxxx.supabase.co`
   - **SUPABASE_ANON_KEY**：`sb_publishable_...` 或 `eyJ...` 开头的长字符串
3. 点击 **连接**：
   - 两个值正确 → 进入登录页
   - 报错「连接失败」→ 回到 [setup-supabase.md 常见问题](setup-supabase.md#常见问题排查)

> 这两个值会保存在本机，下次打开无需重复填写。

## 2. 注册与登录

### 注册

- **账号**：3~32 位字母/数字/下划线，团队内唯一，用于登录
- **密码**：**请务必牢记！** 它同时用于登录和解密你的密钥。忘记密码 = 无法解密任何历史消息，只能换新账号
- **昵称**：展示给团队其他成员的名字

注册成功后自动登录，并加入**全员群**。

### 登录（换台设备）

在另一台设备上填相同的 URL + KEY，然后用**相同账号 + 密码**登录，即可在任意设备上收发消息（最多同时在线设备数无限制）。

> 本应用不保存聊天记录：新设备登录后只会看到**服务端仍保留的**（24 小时内的）消息，历史消息本来就已被服务端销毁。

## 3. 界面速览

```
┌────────────┬────────────────────────────────┐
│ 会话列表    │  聊天窗口                       │
│            │                                │
│ ● 全员群    │  消息气泡（文本/图片/文件卡片）    │
│ ● 张三      │                                │
│ ● 项目小组  │  ────────────────────────────  │
│            │  [输入框]  [图片] [文件] [发送]   │
└────────────┴────────────────────────────────┘
```

- 左侧（手机上是列表页）是会话列表：**全员群**置顶，下面是私聊与群聊
- 点右上角 **＋** 发起新私聊或新建群聊
- 点会话标题/头像 → 会话信息（成员名单、清空记录等）

## 4. 发消息

### 文本

在输入框输入内容，按 **Enter**（手机上点发送键）发送。消息在发送前于本机加密。

### 图片

1. 点击 **图片** 按钮，选择本地图片
2. 图片会加密上传到你的 Supabase 存储区，聊天中只显示**缩略卡片**（不会自动下载）
3. 点击卡片 → 下载并解密 → 在窗口内预览

### 粘贴发送（桌面端快捷方式）

在输入框中直接按 **Ctrl+V**（macOS 为 **Cmd+V**）：

- **截图**（如 Win+Shift+S 截取的截图）：直接以图片发送
- **复制的图片**（如在浏览器/看图软件中复制的图片）：直接以图片发送
- **复制的文件**（资源管理器里 Ctrl+C 的文件/多选文件）：依次发送（一次最多 10 个）
- **普通文本**：按常规粘贴到输入框

### 文件（任意类型）

1. 点击 **文件** 按钮选择文件（单文件建议 ≤ 50MB，Supabase 免费版限制）
2. 对方会看到文件名、大小的卡片（文件名本身也加密）
3. 点击 → **下载** → 解密后保存到你选择的位置

> 图片和文件**不会自动下载**：什么时候看，什么时候下载。附件随聊天记录一起被删除（24 小时后或有人清空会话时）。

## 5. 私聊与群聊

### 和某人私聊

右上角 **＋** → **发起私聊** → 从团队通讯录中选择成员 → 开始聊天。同一对成员始终复用同一个私聊会话。

### 新建群聊

右上角 **＋** → **新建群聊** → 输入群名 → 勾选成员 → 创建。

### 添加群成员

进入群聊 → 右上角信息按钮 → **添加成员** → 选择通讯录中尚未入群的成员。

> 新成员入群后由在线成员自动为其分发会话密钥（界面显示「等待密钥…」时请稍候）。全员群的新成员也走同一机制。

## 6. 清空聊天记录（任何成员都可操作）

进入会话 → 右上角菜单 → **清空聊天记录**：

- **服务端**：该会话全部消息与附件被**硬删除**，不可恢复
- **所有成员设备**：在线设备立即清空内存中的聊天窗口；离线设备下次打开也看不到（因为记录只存在于内存）
- 效果：**你、对方、所有人**都再也看不到这段聊天记录

> 与「24 小时自动销毁」的区别：自动销毁是到点删除旧消息；清空是立刻删除**全部**消息。

## 7. 会话密钥与「等待密钥」

- 每条会话（私聊/群聊）有独立的加密密钥
- 对方/群成员给你发消息前，会用你的公钥把密钥封装给你 —— 全程无需你操作
- 全新成员加入全员群时，若此刻没有任何在线老成员，会短暂显示「等待密钥」：
  - 等待的一方：保持客户端打开，联系任意一位老成员打开他的客户端（无需任何操作），几秒内即自动完成；界面每 30 秒也会自动重新请求，也可点「重新请求」立即触发
  - 老成员一方：什么都不用做，打开客户端会自动响应（包括离线期间积压的历史请求）

## 8. 设置与多设备

设置页（左上角头像/菜单）：

- **修改昵称**：立即生效，团队内所有人可见
- **修改密码**：会同步重新封装你的密钥（旧密码将失效）
- **更新后端配置**：换到另一个团队的 Supabase（相当于切换团队；会退出当前账号）
- **退出登录**：清除本机会话令牌（不影响服务端数据）

## 9. 安全须知（请团队内部达成共识）

1. **密码 = 你的解密钥匙**：不要使用与其他网站相同的密码；忘记密码无法找回历史消息
2. **KEY 即通行证**：`SUPABASE_URL + ANON_KEY` 只发给团队成员；一旦泄露给外部人员，对方可注册进群看**后续**消息
3. **24 小时生命周期**：需要长期留存的内容请自行导出；服务端不提供历史归档
4. **元数据可见性**：服务端（数据库持有者）能看到消息的**收发时间、发送者、所属会话**等元数据（内容仍是密文）。对此敏感的场景请自行评估
